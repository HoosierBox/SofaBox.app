Getting the most out of Ink on Windows and Android.

Windows setup Android setup Emulators Artwork TV & DeX Controls

Windows setup

  1. Run the installer (or the portable version). Ink opens in full screen — press F11 to switch between full screen and a window.
  2. Press + to add games: import your Steam or Epic library, add any PC program, or add a web page.
  3. Xbox controllers: the Guide button brings you back to Ink from any game. To stop Windows from also opening Game Bar, go to Settings → Gaming → Xbox Game Bar and turn off "Open Xbox Game Bar using this button on a controller".
  4. PlayStation and other controllers: turn on Back + Start = Home in Ink's settings, or use the keyboard shortcut Ctrl+Shift+Home.
  5. Want Ink ready whenever you pick up a controller? Turn on Start with Windows. Ink waits in the tray and jumps to full screen when a controller connects.

Android setup

Ink works right after installing. These optional steps make it feel like a console:

  1. Allow restricted settings (needed for apps installed outside Google Play): Settings → Apps → Ink → ⋮ → Allow restricted settings.
  2. Turn on the Home button service: Settings → Accessibility → Installed apps → Ink Home button. This lets your controller's Home button (or Select + Start) bring you back to Ink, opens Ink when you plug into a TV or DeX, and closes the old game when you switch.
  3. Battery: Settings → Apps → Ink → Battery → Unrestricted. On Samsung, also add Ink to Never sleeping apps.
  4. Optional: make Ink your Home app so the phone's Home button always goes to Ink.
Ink's Settings → Android setup shows a ✓ for each step and has a button to open the right Android screen.

Emulators

  1. Install the emulator you want (RetroArch, Dolphin, NetherSX2, DuckStation, PPSSPP, Eden …) and make sure it runs a game on its own.
  2. In Ink: + → Manage emulators → Add emulator and pick the preset. On Windows, point it to the emulator's .exe.
  3. + → Scan a ROM folder and choose the folder with your games. Each game gets a tile.

Tips

  • RetroArch on Android needs All files access (in RetroArch's app settings) and the right core downloaded in RetroArch first.
  • Name ROMs like Super Mario World (USA).sfc to get cover art automatically.
  • If an emulator has no preset, choose Custom. On Windows you can add a post-launch macro that presses keys (for example 3000 {F11} for full screen).

Artwork

Steam games and many emulator games get artwork automatically. For everything else (Switch, Epic, Android …):

  1. Sign in at steamgriddb.com (free), then open Preferences → API and generate a key.
  2. Paste it in Ink: Settings → Artwork, then press Find missing artwork now.

You can also set any image yourself: press X on a game → Change cover art.

TV & Samsung DeX

  • TV (HDMI / USB-C): plug your phone in and Ink moves to the TV, scaled to fit. Your phone's resolution is never changed. Adjust TV interface size and TV safe area in settings.
  • Samsung DeX: Ink runs as an app on the DeX desktop and can open automatically when DeX starts (needs the Home button service).

Controls

  • A / ✕ — play or resume · B / ○ — back
  • X / □ — game options (edit, cover art, favorite, quit) · Y / △ — add games
  • LB / RB — switch tabs · Start — settings · Select — search
  • Home / Guide — back to Ink from any game
  • Keyboard: arrows or WASD, Enter, Esc. Mouse: click, scroll the wheel or drag the tiles; right-click a tile for options.
